# 正式使用前的候选版本检查

本文记录尚未发布的 `0.3.0` 候选版本。本轮代码已针对初始16项问题和后续复查问题作修改。冻结源码已在 Python 3.11、3.13、3.14 下各通过1,081项测试，源码哈希未变；新的独立只读复查已接受所列检查，未再发现问题；这不代表工业认证，也不证明下文未验证项目已经完成。

适用于单个操作系统用户和明确受信任的 SSH 节点。worker、worktree 和文件副本都使用该用户身份，不提供多租户访问控制，也不保证隔离同一用户身份下的恶意进程。见[安全说明](../../SECURITY.md)。

## 本轮修改

下面三份报告描述的是**修复前**的实现，保留其中的重现步骤和原始检查结果作为历史记录。

| 初始审查 | 候选代码针对的问题 |
| --- | --- |
| [核心执行与消息](../industrial-core-review.md)，6项 | 保留内容指纹不同的镜像事件；删除本节点镜像前证明有匹配的原事件；取消尚未发送的远端原生消息；让公开的组消息取消接口实际修改已保存队列；父通知标明远端任务和结果；记录 Codex 工具开始事件。 |
| [安装、更新和 Web 安全](../industrial-install-security-review.md)，6项 | 限制慢 HTTP 请求和处理线程数量；服务迁移明确失败后恢复旧文件及已知状态；OTA 后保留原 bootstrap 设置；移除本机特定代理默认值；规范 macOS LaunchAgent 名称；默认回环 Host 设置支持实际选择的 Web 端口。 |
| [工作目录与结果文件](../industrial-workspace-review.md)，4项 | 多块输入未达到声明长度时继续接收；冲突重试不覆盖已接受块；按 attempt 保留 copy 模式输出；补丁允许在新目录中增加文件，同时检查已有路径组成。 |

后续复查还补了这些修改：

- 配置格式错误、字段类型错误和未知字段返回明确错误；隐藏输入中的敏感名称，失败时保留已有设置。
- 使用已打开的目录文件描述符保留 copy 结果，拒绝父目录符号链接及 FIFO 替换；在数据库写事务内拒绝重叠上传块。
- 安装失败时恢复原 systemd 自启动链接。
- 写服务文件前区分“服务不存在”和“探测结果不明”；服务操作或恢复结果不明时停止，保留恢复信息。恢复文件失败后不再继续操作服务。
- 删除镜像事件时重新检查内容和受保护引用，包括准备删除计划后发生的变化。
- 本地任务需要输入时通知已登记父会话；监控分别显示执行、审查、输入、进程存在与结果不明，HTTP 数据新鲜程度与 broker 连通情况分开记录。

这些内容说明代码改了什么，冻结源码已通过所列项目的独立静态复查。其他用户可见修改见[更新记录](CHANGELOG.md)。
