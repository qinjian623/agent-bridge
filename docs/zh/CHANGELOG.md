# 变更记录

## 尚未发布

- 准备 0.3.1。Linux 和 macOS 打包任务检查 wheel 与 broker 的实际版本并实测 MCP。已有安装可明确切换 GitHub 更新源，移除自定义镜像需显式指定。
- 空状态目录设置按未设置处理；已有目录权限不符时报告错误且不改权限，并提示过长的 Unix socket 路径。
- 整体恢复状态目录后可按 ID 读取任务附件，并说明仍使用绝对路径的其他数据与存储保留规则。
- 交互向导保留探测到的 CLI 路径，定时更新可找到安装在自定义位置的 uv。补充未启用父通知时如何检查结果。

- CLI 帮助、配置向导、终端和 Web 监控、登录页、固定界面错误及父任务通知支持英文与简体中文。增加 `--lang` / `--language`、`AGENT_BRIDGE_LANG`、配置字段 `language` 和浏览器语言选择；协议数据和已排队通知的正文保持不变。

## 0.3.0 — 2026-11-18

这是开源准备后的首个发布版本，不代表通过工业级认证。

- 增加 Apache-2.0 许可证、英文默认文档及中文翻译、简短安装指南和保留数据的卸载说明。
- 增加交互式配置、首次使用时明确选择的 profile、环境检查及清楚的无效配置错误；不会自动把 profile 标为已验证推理。
- 冲突重试不再覆盖已接受的分块；支持跨多个分块的文件和 manifest，以及 patch 传输中新增的嵌套目录文件。
- 按执行批次保留 copy 模式输出，后续任务不会覆盖旧结果。变更记录的 `path` 指向保留文件，`source_path` 指向活动工作区文件。
- 取消尚未发送的本地和远端组消息时不再误报成功；结果不明时拒绝操作，不盲目重发或假装取消完成。
- 父通知明确远端任务身份；本机任务需要输入时通知已登记的父会话。仍需满足通知传输条件，收到通知不代表任务完成或审核通过。
- 镜像清理保留不同内容，并在删除事务中重新检查保留副本和受引用事件。
- 保留已有更新镜像配置，包括仅限回环和 Tailscale 的 HTTP；读取和初始化不会丢掉原更新源，失败时不自动改用 GitHub。
- OTA 后保留有效的 bootstrap 设置；服务操作结果不明时停止后续动作；迁移明确失败时恢复旧服务文件及已知状态。
- 限制 Web 并发请求及慢请求头、请求体，保留认证、Origin/CSRF、SSE 检查和明确的 Host 限制。
- 调整仪表盘布局，区分执行、待审核、等待输入、进程存在和未知状态；HTTP 数据刷新与 broker 连通性分别显示。
- 保留继承或明确留空的代理设置，不指定本机代理端口；SSH 远端命令参数正确引用，不展开 shell 语法。

配置、任务历史和工作目录仍位于仓库以外的私有状态目录。升级前应备份；worktree 和保留结果都不能隔离同一系统用户的其他进程。

发布准备还会检查历史 refs 和旧下载附件。仅发布已检查文件不会删除旧附件或其他克隆中的敏感内容，见[隐私检查](privacy.md)。
